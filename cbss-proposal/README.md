## What changed

- ZIP lookup shows **one depot** and how far it is. It does not list every yard in that city.
- Grade dropdown stays **CW / WWT / One-Trip / As-Is**. Inventory labels are not dumped in.
- Container picker is size (10/20/40/45/53), height (Standard/DC or High Cube/HC), and configuration (standard, tri-door, double door, side door, full open side, other).
- The cash figure is **delivered**. The customer PDF does not add a delivery line on top.

Internal copies still show wholesale, the included delivery, and margin.
